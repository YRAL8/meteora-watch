# meteora-watch

Небольшой read-only скрипт наблюдения: раз в день сохраняет в SQLite метрики пулов Meteora DLMM по SOL-USDC (TVL, комиссии за закрытый день, простая годовая доходность), плюс пишет параметры комиссии из Solana RPC для сверки с API, и строит отчёт/сравнение с Orca SOL-USDC (DeFiLlama) на том же окне дат.
